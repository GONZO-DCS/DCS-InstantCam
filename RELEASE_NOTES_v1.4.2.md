**DCS Instant Cam v1.4.2**

### New since v1.3
- **Tray menu** (camera icon by the clock): photos folder, quick settings, photo resolution, your note for new photos, start with Windows
- **Edit captions after the mission**: change the handwritten lines on any photo, with a live preview
- **Sharper photos**: 1536 px by default (1024 / 2048 selectable), better sampling and anti-aliasing
- **Place names**: nearest airfield on the map ("Near Incirlik" / "34 nm NE of Incirlik")
- Long caption lines shrink to fit; proper aircraft names (F/A-18C Hornet)
- Settings changes apply without restarting DCS
- Installer: optional **desktop shortcut** (tick box)

### Install
Close DCS, download **DCS_InstantCam_Setup_v1.4.2.exe** below and run it (installs over older versions).
If Windows says "Windows protected your PC", click **More info → Run anyway**.
In the cockpit, press **Mouse 4** to raise the camera.
